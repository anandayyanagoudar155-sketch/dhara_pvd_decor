###user_mast

Purpose:
-Stores information of all users who can access the system.
-Differentiates users based on their roles (e.g., admin, employee).
-Tracks login status and creation/update timestamps.

column name		what it stores
user_id			-> Unique ID for each user (Primary Key)
user_name		-> Username of the user
user_password	-> Password of the user
user_role		-> Role of the user (e.g., admin, employee)
is_login		-> Indicates if the user is currently logged in (1 = yes, 0 = no)
created_date	-> Date when the user was created
updated_date	-> Date when the user record was last updated

Notes:
Essential for authentication and role-based access control.
user_id is auto-incremented to ensure uniqueness.
